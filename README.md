# Alize — The Intelligence Interface

World-class premium AI landing interface built with ultra-luxurious, futuristic aesthetic.

**Inspired by:** ChatGPT, Linear, Cursor, Worsel — exceptional typography, spacing, animations, visual hierarchy.

### Design System
- **Cinematic background** — AI-generated futuristic landscape, slightly blurred (18px) with dark overlay & volumetric lighting
- **Floating orbs** — neon blue/purple gradients with drift animations, screen blend
- **Particles** — canvas floating dust with glow, 90 particles, low motion
- **Center glass panel** — 28px radius, `backdrop-filter: blur(36px) saturate(180%)`, frosted glass, thin white border, premium shadow, hover glow following cursor
- **Prompt box** — auto-growing textarea, placeholder "What would you like to create today?", interior dark glass, focus elevation with 4px ring + outer glow
- **Toolbar** — icon-first, left: Upload, Connectors, Templates, Models • right: Voice + Send (glowing accent)
- **Chips** — Design Website, Build App, Generate UI, Create Dashboard, Mobile App, Landing Page, SaaS, AI Agent — hover lift + glow
- **Typography** — Geist + Instrument Serif italic accent, Geist Mono for meta
- **Micro-interactions** — fade-in on load staggered, button hover scaling, send loading, chip insertion, parallax background on mouse move, pulse dot

### Stack
- Pure HTML/CSS/JS, zero dependencies
- Google Fonts (Geist, Instrument Serif, Geist Mono)
- Responsive: desktop, tablet, mobile — toolbar adapts, chips wrap

### Run
Open `index.html` or `npx serve .`
